# pixel-pet-dog

A pet pack for [pixel-pet](../pixel-pet): a floppy-eared puppy in seven coats (tan, chocolate,
cream, white, gray, black, dalmatian). It wags while it stands, gnaws a bone after `/compact`,
and its tail sticks out of the futon.

Install pixel-pet first (this pack depends on it), then `/pet dog`.

It is also the example to copy for a pack of your own: [hooks/dog.ts](hooks/dog.ts) is all the
drawing, [hooks/register.ts](hooks/register.ts) the one hook that hands it to pixel-pet. How to
draw one: pixel-pet's README.
